# Telegram Bot with Python

A simple and lightweight Telegram bot built in Python, following the guide by Timur Khashtamov. This project serves as a starting template for creating custom interactive bots using the Telegram Bot API.

## Features

* Telegram Bot integration using Python.
* Handles basic commands (`/start`, `/help`) and user interactions.
* Easily extensible for custom commands, webhooks, or API integrations.

## Prerequisites

* Python 3.10 or higher.
* A Telegram account and a bot token obtained via [@BotFather](https://t.me/BotFather).
